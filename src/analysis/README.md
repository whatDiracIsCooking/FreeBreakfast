# Analysis

Wavefunction analysis: properties read off orbitals a calculation already has,
without changing them.

## Sub-modules

| Directory | Module | Role |
|-----------|--------|------|
| `population/` | `free_breakfast.analysis.population` | Atomic populations of orbitals over an orthonormal atom-owned minimal basis such as the IAOs (`orbital_populations`), and partial charges from them (`partial_charges`) |

## Files

| File | Role |
|------|------|
| `CMakeLists.txt` | Adds the sub-directories |
