# Exchange

The Cartesian exchange matrix `K_ab = Σ_cd D_cd (ac|bd)` of an AO density, by
McMurchie–Davidson, on the GPU, from kernels generated by
[FelizJueves](../../../deps/FelizJueves) (`Target.K`, `kernel_k.py`).
**Schwarz-screened** at `tau` (default `1e-10`): a lane of `k` stops at its
first ket with `Ip · Iq · max|D| < tau`.

## Module

`free_breakfast.integrals.exchange`, also re-exported by
`free_breakfast.integrals`. It re-exports
[`free_breakfast.integrals.exchange.pairs`](pairs/README.md), so the one
import gives both the ordered classes the build reads and the build:

```cpp
auto mmd = primitive_pair_classes(res, basis);              // once per basis
auto classes = ordered_pair_classes(res, basis, *mmd);      // once per basis
FBF_TRY(exchange(res, *classes, density, k));               // per density
```

## Design

FelizJueves's `k_driver` (`test/plan_driver.py`) is the launch contract. K has
no symmetry inside a pair, so its bra `(a, c)` and ket `(b, d)` are **ordered**
shell pairs, the first shell of each an output index: every
[ordered class](pairs/README.md) is both a bra class and a ket class, and the
generated `k<la, lc, lb, ld>` (`kernels/k/`, dispatched as
`k_kernels[la][lc][lb][ld]`) is one per (bra class, ket class). Each record's
Schwarz bound is `mmd`'s `bound` field, formed once per basis; `k` reads it
as `Ip` on the bra and `Iq` on the ket.

`exchange(res, classes, density, k)` runs:

1. On `res.stream()`: zero `K` and every bra class's blocks, then `max|D|`
   (`exchange_density_max`, `helpers/`).
2. **The rank tables**, each class `(l, l)` on its own stream: the AO offset of
   every shell of momentum `l` by rank, read off its records' `rank_b` and
   `off_b` (`exchange_rank_offsets`). A class `(l, l)` names every shell of `l`,
   each paired with itself. The join closes the phase: every gather reads two
   tables.
3. **The density blocks**, each class `(lc, ld)` on its own stream: `Dcd` of
   `(lc, ld)`, gathered from `D` (`exchange_gather_dcd`). Every `(lc, ld)` of
   two reached momenta is a reached class, so each `Dcd` has a stream. The join
   closes the phase: every bra class reads them.
4. **Every class as a bra**, each on its own stream: its `Ip` and its `Dcd`
   rows; then, for every ket class and every `b` group of it, one `k` launch
   of the bra's records **of first shell `a <= b`** against **the group's**
   kets (`n_bra` that prefix's length, `n_ket` the group's count, every ket
   pointer offset by its start) into the `(bra class, b)` block, none when the
   prefix is empty; then its blocks scattered into `K`, mirrored
   (`exchange_scatter_block`), in that order.

**The bra-ket swap.** `(ac|bd) = (bd|ac)`, so for a symmetric `D`,
`K_ba = K_ab^T`: only the shell blocks `a <= b` need computing. The ordered
classes make that free of any kernel change: each class's records are grouped
by first shell, the groups in basis order, so the bras with `a <= b` are a
**prefix** of every bra class whatever its momenta, cut on the host per
(bra class, `b`) from the class's groups and passed as `kernel_k`'s `n_bra`.
The scatter then adds each `a < b` block **and its transpose** into `K`; an
`a == b` block is computed whole (both members of each of its orbits are in
it) and added once, untransposed. What is left of the duplication is inside the
`a == b` blocks: `O(n_shells)` of `O(n_shells^2)`. This is the K build of
Palethorpe, Stocks & Barca (arXiv:2407.21445, §4.3.1), and FelizJueves's
`ao/k.py` "THE TWO SWEEPS" has the identity and the unique-sweep reference.

**The precondition is a contract, not a check.** The symmetric sweep is only
`K` for a symmetric `D`, and `exchange` does not verify it: refusing would
cost a device pass over `D` *and* a host synchronization to read the verdict
back into the `Status`, where the build is otherwise fully asynchronous. So
`symmetric` (default `true`) is the switch: `false` launches every bra record
against every ket group and mirrors nothing, `K_ab` and `K_ba` each computed
directly, correct for any `D` at twice the work. Handed a non-symmetric `D`,
the symmetric sweep returns its `K`'s `a <= b` blocks, mirrored.

What the kernels leave to the launcher, and how it is supplied:

| Input | Value | Why |
|---|---|---|
| bra fields | `p_*`, `zeta`, `pa_*`, `pb_*`, `s` of the bra class as `p_*`, `zeta_ac`, `pa_*`, `pc_*`, `s_ac` | "a" is a record's first shell, "b" (here `c`) its second |
| ket fields | the ket class's same fields, from the group's start, as `q_*`, `eta`, `qb_*`, `qd_*`, `s_bd`, `Iq` = `bound` | the ket's first shell is `b`, its second `d` |
| `Ip`, `maxD` | `Ip = bound · max\|D\|` (`exchange_bra_bound`), `maxD = 1` | `k` takes `maxD` by value, a host double, but `max\|D\|` is on the device, and reading it back would synchronize the host. The screen is the same product |
| `dc`, `dd` | `dc = rank_b · n_shells(ld)` per (bra class, `ld`) (`exchange_bra_rows`), `dd = rank_b` | the gather's `Dcd` row is `rank_c · n_shells(ld) + rank_d`; `dc` depends on the ket's `ld`, so a bra class has one row set per `ld` and none is stored |
| `n_dc` | `n_shells(lc) · n_shells(ld)` | an extent only, never read |
| kets in order | each group non-increasing in `bound` (`ordered_pair_classes`) | the screen is a `break`: unsorted kets make it a wrong answer, not a slow one |
| the block | `(bra class, b)`, `n_rec × n_x(la) n_x(lb)`, zeroed | `k` `atomicAdd`s into `K[bra · n_a n_b + a n_b + b]`, and every ket class of every `ld` with that `b` adds into the one block |
| the launch | grid `n_rec`, block `k_block_dim = {1, FJ_WAVEFRONT}`, **no dynamic shared memory** | `k`'s `Ksh[(n_p + n_a n_b) · FJ_WAVEFRONT]` is static, sized for exactly that block |

**The shared-memory budget is checked at compile time.** `Ksh` is static, so
`exchange_launch.cu` `static_assert`s the formula
`(n_p + n_a n_b) · k_block_dim[1] · 8` bytes, `n_p = (lp+1)(lp+2)(lp+3)/6`,
`lp = la + lc`, at the largest class, `(dd|dd)`, against 48 KiB: 71 slots,
18,176 B at 32 lanes and 36,352 B at 64. Beside it, the table's extents against
`kMaxAngularMomentum` and `k_block_dim` against `kWarpSize`.

**The blocks.** A bra class's blocks are one buffer, `n_rec × n_x(la) × n_ao`
doubles, shell `b`'s block at `n_rec · n_x(la) · off(b)`, so the AO offsets
lay them out with no table. A block is scattered once, by its `b` shell, its
`a <= b` prefix only; the symmetric sweep leaves the other rows zero, so about
half of the buffer is written.

The scratch (the blocks, `n_rec` doubles of `Ip` and `(l_max + 1) n_rec`
`int32`s of `dc` per bra class; one `Dcd` per class; one rank table per
momentum; one double of `max|D|`) is drawn from `res.device()`'s pool in
`res.stream()`'s order and returned in its order once every phase is joined
back, so there is no host synchronization. The shells' AO offsets and the
shell counts by momentum are read on the host off the classes' groups and
their pinned `off_a`, which `ordered_pair_classes` wrote before its copies.

**One text serves both warp widths.** `k` is emitted `any_wavefront`: its
shuffles and its shared array read `FJ_WAVEFRONT`, which `deps/CMakeLists.txt`
sets from `WWR_WARP_SIZE`.

**Generated kernels are committed, not built.** `tools/emit_exchange_kernels.py`
writes `kernels/k/` from the FelizJueves submodule; re-run it after bumping the
submodule. `kernels/.clang-format` turns formatting off, and
`devtools/check-int-types.py` skips a file by FelizJueves's banner, so the files
stay byte-for-byte as emitted: a fix belongs in the generator.

## Not done

- **The swap inside the diagonal blocks.** An `a == b` block is computed
  whole, so its quartets are still visited twice: `O(n_shells)` blocks of
  `O(n_shells^2)`.
- **Half-sized blocks.** The symmetric sweep writes only the `a <= b` rows of
  a bra class's `n_rec × n_x(la) × n_ao` blocks; a layout holding only those
  would about halve that scratch.
- **Batching.** One `k` launch per (bra class, ket class, `b` group), all of the
  bra's records at once, as FelizJueves ships it; no split class, and the
  blocks are `n_rec × n_x(la) × n_ao` per bra class with no batching of bras
  to bound them.
- **Reuse across SCF iterations.** The scratch, the rank tables and `Dcd` are
  allocated and rebuilt per call.

## Public API

| Symbol | Role |
|---|---|
| `exchange(res, classes, density, k, tau = 1e-10, symmetric = true)` | `Status`: the Cartesian K of `density` into `k`, from `ordered_pair_classes` of the same basis, screened at `tau` (`0` screens nothing), by the `a <= b` blocks mirrored (`symmetric`, which requires a symmetric `density`, unchecked) or every block directly. InvalidConfig for a negative or NaN `tau`, another device, a density of another order, a class above d, a shell past `k`'s order, or `k.n()^2` past `INT32_MAX` |
| `OrderedPairClass`, `ordered_pair_classes`, ... | re-exported from [`pairs/`](pairs/README.md) |

## Tests

`test/gtest/exchange_gpu.cpp`: `K` of H₂O in STO-3G and cc-pVDZ against
libcint's `vk` of the same density at `1e-12 · max|K|`, through the golden data
in `test/gtest/data/exchange/`, both at `tau = 0` and at the default (each run
records its worst error, and how far the screen moved `K`); `K` symmetric to
the same bar; the symmetric sweep against the full one at both `tau`s, with
the share of the full sweep's (bra, ket) record pairs it launches recorded
(0.58 in cc-pVDZ, 0.60 in STO-3G: the diagonal blocks weigh more in a small
basis, and the share falls toward a half as the shells grow in number); on a
non-symmetric density, the symmetric `K` equal to the full one's `a <= b`
blocks and their transposes, not its own `a > b` blocks, which shows those are
mirrored, never computed; a `tau` above every bound gives exactly zero, which shows the
screen reaches the kernel and fires; the zeroing; and the refusals. The
helpers are `exchange_helpers_gpu.cpp`'s test and the classes
`exchange_pairs_gpu.cpp`'s.
