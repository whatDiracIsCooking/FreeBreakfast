# Kinetic

The Cartesian kinetic-energy matrix T on the GPU, over the `t_{la}{lb}`
kernels FelizJueves generates.

> **Currently disabled.** This module is not built, linked or re-exported,
> and its test (`test/gtest/core_hamiltonian_gpu.cpp`) is off; the sources
> are kept. See `../CMakeLists.txt` for what to uncomment to restore it.

## Module

`free_breakfast.integrals.one_electron.kinetic`, also re-exported by
`free_breakfast.integrals.one_electron` and `free_breakfast.integrals`.

## Design

`kinetic` runs `check_one_electron_build` (`upload`), zeroes the
`CartesianMatrixAO`, and launches one generated kernel per class, one thread per
record. The kernels read the overlap's record fields plus `eb`, the ket
exponent. Each thread adds its values at `(m, n)` and `(n, m)` with fp64
atomics, so T is symmetric to rounding, not bitwise. Queued on `res.stream()`,
each class on its own stream, forked from it and joined back into it
(`DevicePrimitivePairs::launch_each`), with no host synchronization.

`core_hamiltonian` calls `kinetic` to zero H and write T, then adds V on top.

**The kernels.** `kernels/t_{00,01,02,11,12,22}.cu` (every `la <= lb <= 2`),
generated by `tools/emit_one_electron_kernels.py` and committed as emitted.
Each is one explicit specialization of the kernel template `kinetic`, compiled
as a source of the device library; `kinetic_launch.cu` includes only
`kernels/kinetic.h` and launches through its `kinetic_kernels` table.

**The family layout** is `overlap/`'s; the parent README's "One layout per
kernel family" has the table.

**Limits.** d per shell (`kMaxAngularMomentum`), and `n_ao² ≤ INT32_MAX`;
either is `InvalidConfig` before anything is launched. The records' AO offsets
are not checked against the matrix's order: the classes must come from the
basis the matrix was made for.

## Public API

| Symbol | Role |
|---|---|
| `kinetic(res, pairs, t)` | `Status`: the Cartesian T into `t` |

## Usage

```cpp
import free_breakfast.integrals.one_electron.upload;
import free_breakfast.integrals.one_electron.kinetic;
import free_breakfast.linalg.matrix_ao;
namespace fb = free_breakfast;

const auto device = fb::upload_primitive_pairs(res, basis);  // once per basis
fb::CartesianMatrixAO t(res, basis);
fb::Status status = fb::kinetic(res, *device, t);
```

## Tests

`test/gtest/core_hamiltonian_gpu.cpp`: H₂O in STO-3G and cc-pVDZ against
libcint's `int1e_kin` at 1e-12 · max|T|, plus the zeroing and the class-range
refusal.
