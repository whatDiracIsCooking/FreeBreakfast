# Dipole

The Cartesian dipole matrices mu_x, mu_y, mu_z on the GPU, about the origin,
over the `dipole<la, lb>` kernels FelizJueves generates (its `Target.DIPOLE`,
`kernel_mu`).

## Module

`free_breakfast.integrals.one_electron.dipole`, also re-exported by
`free_breakfast.integrals.one_electron` and `free_breakfast.integrals`.

## Design

`dipole` runs `check_one_electron_build` (`launch`) on `mu_x`, requires
`mu_y` and `mu_z` to match it, refuses any class above d, then zeroes a
`3 n²` region of `res.device_workspace()` and launches one generated kernel per
class, one thread per record. Each thread forms the record's E tables once and
adds all three components at `(m, n)` and `(n, m)` with fp64 atomics, into
`[3, n, n]`; each component is then copied into its own `CartesianMatrixAO`.
Three separately allocated matrices are not one array, hence the workspace.
Each matrix is symmetric to rounding, not bitwise. Queued on `res.stream()`,
each class on its own stream, forked from it and joined back into it
(`launch_each`), with no host synchronization.

mu_d,mn = <m| r_d |n>, the electronic position operator about the origin, the
sign and origin of libcint's `int1e_r`: the kernels take the origin C and a
charge q at run time, and the launcher passes C = 0 and q = 1. A caller
wanting another origin shifts by its overlap, mu(C) = mu(0) − C S. The
spherical matrices are `MatrixAOPair::cartesian_to_spherical` of each.

**The kernels.** `kernels/mu_{00,01,02,11,12,22}.cu` (every `la <= lb <= 2`),
generated by `tools/emit/one_electron_kernels.py` and committed as emitted,
each one explicit specialization of the kernel template `dipole`;
`kernels/dipole.h` declares them and holds `dipole_kernels`, the 3 × 3 table
`dipole_launch.cu` launches through. The family layout is the parent README's
"One layout per kernel family".

**Limits.**

- d per shell (`kDipoleMaxL`), below the other families' f: FelizJueves
  validates `kernel_mu` against libcint through (dd) only, and its emitter
  refuses `--mu-l 3`. A basis with an f shell is `InvalidConfig` naming the
  limit, before anything is launched. Reaching f is FelizJueves#627 (perhaps a
  low-stack variant, as V needed at f), then a pin bump, a re-emit here and
  dropping the check.
- `3 n² ≤ INT32_MAX` (about 26k Cartesian AOs): the kernels index all three
  components as one 32-bit offset.
- The records' AO offsets are not checked against the matrices' order: the
  classes must come from the basis the matrices were made for.

## Public API

| Symbol | Role |
|---|---|
| `dipole(res, classes, mu_x, mu_y, mu_z)` | `Status`: the three Cartesian dipole matrices |
| `kDipoleMaxL` | The largest momentum the kernels cover: d |

## Usage

```cpp
import free_breakfast.integrals;
import free_breakfast.recipes.matrix_ao;
namespace fb = free_breakfast;

const auto classes = fb::primitive_pair_classes(res, basis);  // once per basis
const auto u = fb::upload_spherical_transform_matrix(res, basis);
std::array<fb::MatrixAOPair, 3> mu{fb::MatrixAOPair(res, basis, *u),
                                   fb::MatrixAOPair(res, basis, *u),
                                   fb::MatrixAOPair(res, basis, *u)};
fb::Status status = fb::dipole(res, *classes, mu[0].cartesian(), mu[1].cartesian(),
                               mu[2].cartesian());
for (auto &m : mu) {
  status = m.cartesian_to_spherical(res);
}
```

## Tests

`test/gtest/dipole_gpu.cpp`: H₂O in STO-3G and cc-pVDZ, carried to the
spherical layout, against libcint's `int1e_r_sph` at origin 0
(`test/gtest/data/cis/`, written by `tools/emit/cis_reference.py`) at 1e-12
absolute (measured 2e-16 and 7e-16), each element divided by N_i N_j first,
N_i = sqrt(S_ii): PySCF unit-normalises each contracted function and this
tree only its primitives; plus the zeroing, the refusal of an f shell, and of three matrices
of different orders.
