# One-electron

One-electron integral matrices on the GPU, over kernels FelizJueves generates.
Today: the overlap S.

## Module

`free_breakfast.integrals.one_electron`, also re-exported by
`free_breakfast.integrals`.

## Design

`upload_primitive_pairs` copies `mmd`'s records to the device once per basis.
`overlap` then zeroes a `CartesianMatrixAO` and launches one generated kernel
per class, `s_{la}{lb}`, one thread per record. Each thread adds its values at
`(m, n)` and `(n, m)` with fp64 atomics, so S is symmetric to rounding (the two
mirror positions are summed in different orders), not bitwise. The spherical S
is `MatrixAOPair::cartesian_to_spherical` of the result.

**The kernels.** `s_overlap/s_{00,01,02,11,12,22}.cu`, every `la <= lb <= 2`,
generated by `tools/emit_one_electron_kernels.py` and committed as emitted. They
are FelizJueves's CUDA spelling plus wwr's `#include <runtime.h>`, which makes
the same text compile under clang `-x hip`. `overlap_launch.cu` `#include`s them
rather than compiling them as sources of their own, so it launches kernels whose
definitions it can see; listing them as sources too would define each `extern
"C"` kernel twice.

**Limits.**

- d per shell (`device::kOverlapMaxAngularMomentum`); a class above is
  `InvalidConfig`, before anything is launched.
- The kernels index S as a 32-bit `m * n_ao + n`, so `n_ao² ≤ INT32_MAX`
  (about 46k Cartesian AOs); above is `InvalidConfig`.
- The records' AO offsets are not checked against S's order: the classes must
  come from the basis S was made for.

## Public API

| Symbol | Role |
|---|---|
| `DevicePrimitivePairClass` | One class's records on the device, the same fields as `PrimitivePairClass` |
| `upload_primitive_pairs(res, classes)` | `Result<std::vector<DevicePrimitivePairClass>>`. Synchronizes once, so the host classes may be released on return |
| `overlap(res, classes, s)` | `Status`: the Cartesian S into `s`, queued on `res.stream()`, no host synchronization |

## Usage

```cpp
import free_breakfast.integrals;
import free_breakfast.linalg.matrix_ao;
namespace fb = free_breakfast;

const auto classes = fb::primitive_pair_classes(basis);       // host
const auto device = fb::upload_primitive_pairs(res, *classes); // once per basis
fb::CartesianMatrixAO s(res, basis);
fb::Status status = fb::overlap(res, *device, s);
```
