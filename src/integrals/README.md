# Integrals

Gaussian integrals over a `BasisSet`, on the GPU, with kernels generated by
[FelizJueves](../../deps/FelizJueves) (a submodule at `deps/FelizJueves`).

## Module

`free_breakfast.integrals`, which re-exports the two below.

```
mmd/           free_breakfast.integrals.mmd: host-side McMurchie-Davidson primitive-pair records
one_electron/  free_breakfast.integrals.one_electron: the one-electron matrices (today S) on the GPU
```

## How the pieces fit

```
BasisSet --primitive_pair_classes--> PrimitivePairClass[]          (mmd, host)
         --upload_primitive_pairs--> DevicePrimitivePairClass[]    (one_electron, once per basis)
         --overlap-->                CartesianMatrixAO S           (one launch per class)
         --MatrixAOPair::cartesian_to_spherical-->  spherical S    (linalg.matrix_ao)
```

**Generated kernels are committed, not built.** `tools/emit_one_electron_kernels.py`
writes them from the FelizJueves submodule; a build never runs Python. Re-run it
after bumping the submodule. Each family has its own directory
(`one_electron/s_overlap/`), whose `.clang-format` turns formatting off, and
`devtools/check-int-types.py` skips a file by FelizJueves's first-line banner:
the files stay byte-for-byte as emitted, so a fix belongs in the generator.

**One class per unordered pair of momenta.** `mmd` swaps every shell pair into
`la <= lb`, so `(s|p)` has a kernel and `(p|s)` does not need one. The
matrices are symmetric and the kernels write each value at `(m, n)` and
`(n, m)`, so the swap changes nothing about the result.
