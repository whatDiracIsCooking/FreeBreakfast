# Coulomb

The Coulomb matrix `J_µν = Σ_λσ (µν|λσ) D_λσ` by McMurchie–Davidson, from
kernels generated by [FelizJueves](../../../deps/FelizJueves). **Only the
kernels exist so far:** they are compiled into a device library and checked at
compile time, and nothing launches them yet. There is no module, launcher or
test of a `J` here.

## The build the kernels are for

FelizJueves's `docs/implementation/j_engine.md`, "The J chain as device code",
is the contract. Per primitive-pair record (`free_breakfast.integrals.mmd`):

| Step | Template | One per | Computes |
|---|---|---|---|
| ket pre-contraction | `dq<lc, ld>` | ket pair class, `lc <= ld` | `D_q = w Σ_cd D_cd s E^cd_q` and `Dmax = max_q \|D_q\|`, reading the AO density in place |
| `[p\|q]` | `e_hermite<lp, lq>` | Hermite class, `lp, lq <= 4` | `J_p += Σ_q [p\|q] D_q`, one warp per bra record, kets strip-mined, `J_p` added atomically |
| bra transform + scatter | `jab<la, lb>` | bra pair class, `la <= lb` | `J_ab += Σ_p s E^ab_p J_p`, added atomically into `J_µν` |

What a launcher will have to supply, because the kernels do not decide it:

- `w`, 2 for an off-diagonal shell pair and 1 for a diagonal one;
- `J_p` zeroed per bra class, and `J_µν` zeroed, before the first launch;
- `e_hermite` launched with `blockDim = e_hermite_block_dim` (`{1, FJ_WAVEFRONT}`)
  and nothing else: its shared `J_p` accumulator is sized for exactly that block;
- kets sorted descending by `Iq · Dmax` whenever `tau > 0`, because the screen
  `break`s. With `tau = 0` the screen never fires and the order is free.

## Layout

```
kernels/dq/         dq_{lc}{ld}.cu, dq.h                 6 classes
kernels/e_hermite/  e_hermite_{lp}{lq}.cu, e_hermite.h  25 classes
kernels/jab/        jab_{la}{lb}.cu, jab.h               6 classes
coulomb_kernels.cu  the compile-time checks
```

**Generated kernels are committed, not built.** `tools/emit_coulomb_kernels.py`
writes them from the FelizJueves submodule; re-run it after bumping the
submodule. `kernels/.clang-format` turns formatting off, and
`devtools/check-int-types.py` skips a file by FelizJueves's banner, so the
files stay byte-for-byte as emitted: a fix belongs in the generator.

**One text serves both warp widths.** `e_hermite` is emitted `any_wavefront`:
its shuffles and its shared array read `FJ_WAVEFRONT`, which
`deps/CMakeLists.txt` sets from `WWR_WARP_SIZE`. `dq` and `jab` have no
shuffle. Record vectors are three flat arrays per axis, named as `mmd` names
its fields (`pa_*`, `pb_*`; `p_*` and `q_*` for the `[p|q]` centres).

## What is checked

`coulomb_kernels.cu` `static_assert`s that each table was emitted for
`kMaxAngularMomentum` and that `e_hermite_block_dim` is `{1, kWarpSize}`. The
C++ tier compiles every unit, and `devtools/cross-backend-check.sh` compiles
them under the other backend. Nothing checks that every table entry links:
that needs an executable that takes their addresses, the launcher's.
