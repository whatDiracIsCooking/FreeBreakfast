# e_hermite

The J build's `[p|q]` contraction on the GPU, over the `e_hermite<lp, lq>`
kernels FelizJueves generates: `J_p += Σ_q [p|q] D_q`, one ket class against
every bra class, Schwarz-screened.

## Module

`free_breakfast.integrals.eri.integral_direct.coulomb.e_hermite`, driven by
`free_breakfast.integrals.eri.integral_direct.coulomb`'s `coulomb`.

## Design

`e_hermite(ket, bras, tau)` launches on the ket class's own stream, one
generated kernel per bra class, one warp per bra record with the kets
strip-mined across its lanes, each adding into the bra's `J_p` atomically. It
reads the ket as the last build sorted it (its `ket_` fields, descending by
`Iq · Dmax`), so a lane can stop at its first ket with `Dmax · Ip · Iq < tau`;
the bras are read in record order, `Ip` their own `bound`.
[`../README.md`](../README.md) has the build and the screen.

It checks nothing: `coulomb` has checked the classes first.

**The kernels.** `kernels/e_hermite_{lp}{lq}.cu`, every `lp, lq <= 6` (an
f-shell pair's E reaches `|t| = 6`), generated by
`tools/emit_coulomb_kernels.py` and committed as emitted, `any_wavefront`: one
text for a 32- and a 64-lane build. Each is one explicit specialization of the
kernel template `e_hermite`, compiled as a source of the device library;
`e_hermite_launch.cu` includes only `kernels/e_hermite.h`, launches through its
`e_hermite_kernels` table with its `e_hermite_block_dim`, and asserts that
block against `kWarpSize`.

**The family layout** is `../../../../one_electron/overlap/`'s; that parent README's
"One layout per kernel family" has the table.
