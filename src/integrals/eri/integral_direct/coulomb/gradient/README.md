# gradient

The J energy's nuclear-gradient step on the GPU, over the `gjab<la, lb>`
kernels FelizJueves generates: per bra record, the bra derivative of `E_J`
contracted with the density against the record's raised `J_p`, added into a
per-atom `G`. A device library only; `coulomb_gradient`
([`../README.md`](../README.md), "The nuclear gradient") drives it.

## Design

`coulomb_gradient_class(stream, cls, rows, ao_atom, atoms, n_ao, n_atom, jp,
m, g)` (`coulomb_gradient_bridge.h`) first gathers each record's two atoms
from `ao_atom` (each Cartesian AO's atom) into `atoms`, then launches
`gjab<cls.la, cls.lb>`, one thread per record, `kFourWarps` to a block, which
adds `s Σ (dA_k E^ab)·J_p` into `G[atom_a, k]` and the B term into
`G[atom_b, k]` atomically. `jp` is the class's `J_p` one Hermite order up,
`n_rec × n_hermite(la + lb + 1)`, which `e_hermite` at `raise = 1` wrote; `m`
is the Cartesian density, symmetric; `G` is zeroed by the caller. `cls` is
J's class's view with `mmd`'s `ea` and `eb` set (J's classes do not carry the
exponents, and the derivative's `2 alpha` needs them).

**The kernels.** `kernels/gjab_{la}{lb}.cu`, every `la <= lb <= 3`,
generated by `tools/emit/coulomb_kernels.py` and committed as emitted: the
`gjab_` half of FelizJueves's `--grad-l 3` ladder, each class in
FelizJueves's default form (`kernel_gjab.gjab_lowstack`: low-stack from
`la + lb = 5`, (df)/(fd)'s `gjab_23` and (ff)'s `gjab_33`; unrolled below).
They have no shuffle, so their text has no width. Each is one explicit
specialization of the kernel template `gjab`; the launcher includes only
`kernels/gjab.h`, launches through its `gjab_kernels` table, and asserts it
against `kCoulombMaxMomentum`.

**The family layout** is `../../../../one_electron/overlap/`'s; that parent
README's "One layout per kernel family" has the table.
